Equipos Audiovisuales Disponibles

Proyector HD

Proyector portátil con resolución HD ideal para presentaciones y conferencias.

Instrucciones para préstamo:
  1. Verifica la disponibilidad del equipo en la lista.
  2. Llena el formulario de solicitud de préstamo.
  3. Presenta tu identificación oficial en la oficina de préstamos.
  4. Firma el documento de responsabilidad.
Cámara DSLR

Cámara profesional DSLR con lente intercambiable para fotografía y video.

Instrucciones para préstamo:
  1. Confirma el propósito del préstamo con el encargado.
  2. Llena el formato de solicitud con tus datos completos.
  3. Deja un depósito en garantía (si aplica).
  4. Revisa el equipo antes de llevártelo.
Micrófono Inalámbrico

Micrófono inalámbrico de alta calidad para presentaciones y grabaciones.

Instrucciones para préstamo:
  1. Consulta las fechas disponibles con el administrador.
  2. Llena el formulario digital o físico para solicitar el equipo.
  3. Asegúrate de firmar el contrato de responsabilidad.
  4. Recoge el equipo en el horario acordado.
