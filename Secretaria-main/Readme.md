

Página Web para la Secretaría de Difusión y Edición Editorial

Este proyecto fue desarrollado como parte de mi servicio social y consiste en una página web para la Secretaría de Difusión y Edición Editorial. Su objetivo es mejorar la comunicación y visibilidad de las publicaciones, eventos y actividades de la secretaría.

📌 Características

Diseño responsivo para una mejor experiencia en distintos dispositivos.

Sección de noticias y eventos para mantener informados a los usuarios.

Gestión de publicaciones para visualizar ediciones editoriales destacadas.

Optimización SEO para mejorar la visibilidad en buscadores.
